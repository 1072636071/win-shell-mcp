# 02-命令注册表与核心横切能力

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 用户能通过 MCP 调用第一批工具（`pwd`、`echo`）。命令注册表机制落地：每命令声明式注册 短名 / 别名 / 参数 schema / 描述，server 启动时动态装载，`tools/list` 同时暴露短名与别名。核心横切能力就位：输出精简契约（token 最小化）、路径标准化、编码处理（GBK/CP936→UTF-8）。

**验收标准：**

- [ ] 注册表声明式注册机制可用，短名与别名指向同一实现
- [ ] `tools/list` 同时列出短名与别名；`tools/call` 用短名或别名调用结果一致
- [ ] 每个工具的 description 注明「≈ Unix 的 xxx」及 Windows 对应命令
- [ ] 参数缺失/类型错误返回简短、结构化、可行动的错误
- [ ] 输出为精简结构化 JSON，无装饰性格式化，token 最小化（ADR-0003）
- [ ] 路径标准化与编码 util 落地并被 `pwd`/`echo` 使用
- [ ] 协议层 seam 测试覆盖：注册装载、别名一致性、参数校验失败
