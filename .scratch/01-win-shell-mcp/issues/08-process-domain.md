# 08-进程与环境变量命令域

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 用户能管理进程与环境：`ps`（列出进程）、`kill`（按 pid 或名称终止）、环境变量读写。纯 Node 实现，跨平台行为一致。遵循输出精简原则与信任模式。

**验收标准：**

- [ ] `ps` 返回精简进程列表（pid、名称、关键元数据）
- [ ] `kill` 按 pid 终止成功；按名称终止成功或返回明确错误
- [ ] 环境变量读取返回当前值；写入可作用于后续 run_command（与 03 配合）
- [ ] 不存在的 pid/进程返回结构化错误
- [ ] 协议层 seam 测试覆盖成功/失败/边界
