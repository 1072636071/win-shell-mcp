# fs 只读工具集

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** AI 可直接列出目录内容、读取任意文本文件（含 Windows 中文 GBK 编码自动识别、长内容截断）并查看文件信息（类型/大小/修改时间），全程无需手写 shell 命令。

**验收标准：**

- [ ] 列目录返回相对路径列表，verbose 时含类型/大小
- [ ] 读文件支持行/字节范围与截断标记，GBK 与 UTF-8 文件均正确解码
- [ ] 文件信息含 type/size/mtime
- [ ] 覆盖不存在路径、目录误读、无权限等错误路径并有测试
