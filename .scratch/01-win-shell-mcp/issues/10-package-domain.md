# 10-包管理命令域

**Status:** ready-for-agent

**Blocked by:** 03

**构建内容：** 用户能检测并执行常见包管理器（`npm`/`pip`/`cargo`）。内部经 run_command 逃生舱执行真实包管理器命令，自动处理 Windows 上的可执行文件后缀与路径差异。遵循输出精简原则。

**验收标准：**

- [ ] 能检测系统已安装的包管理器（含 `.cmd`/`.exe` 后缀处理）
- [ ] 对已安装的包管理器执行常用操作（如版本查询）并返回精简结果
- [ ] 未安装的包管理器返回明确的结构化提示
- [ ] 协议层 seam 测试覆盖检测与执行
