# 06-搜索命令域

**Status:** ready-for-agent

**Blocked by:** 04, 05

**构建内容：** 用户能定位可执行文件（`which`，PATH 搜索，Windows 含 .exe/.cmd 后缀）与搜索文件：按 glob 模式匹配、按文件名模式遍历搜索（递归与忽略规则）、按内容搜索（复用文件系统与文本处理域能力，返回命中的文件/行/文本）。遵循输出精简原则与信任模式。

**验收标准：**

- [ ] `which` 能返回已安装命令的绝对路径，未找到时返回明确结果
- [ ] 按 glob 匹配返回文件路径列表（可递归）
- [ ] 文件名模式搜索返回匹配路径列表，支持递归与忽略规则
- [ ] 内容搜索返回 `[{file, line, text}]`，长结果截断
- [ ] 空结果、无权限目录、非法 glob 等边界返回结构化结果
- [ ] 协议层 seam 测试覆盖成功/失败/边界
