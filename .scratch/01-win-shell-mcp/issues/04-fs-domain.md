# 04-文件系统命令域

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 用户能通过 MCP 在真实文件系统中完成文件/目录操作。读：`ls`（列目录，verbose 含类型/大小）、读文件（支持行/字节范围、GBK/UTF-8 编码自动识别、长内容截断）、`stat`（文件信息）。写：写文件（含指定编码）、`mkdir`（递归创建）、`rm`（递归删除）、`cp`、`mv`、`touch`。搜索：`find`（按文件名模式递归搜索）。全部路径参数自动标准化（分隔符/绝对相对/盘符），行为与 Unix 语义一致，遵循输出精简原则与信任模式。

**验收标准：**

- [ ] 列目录返回相对路径列表，verbose 时含类型/大小
- [ ] 读文件支持行/字节范围与截断标记，GBK 与 UTF-8 文件均正确解码
- [ ] 文件信息含 type/size/mtime
- [ ] 写文件（含指定编码）、建目录（可递归）；删除文件/目录（可递归）、复制、移动/重命名
- [ ] touch 创建空文件或更新 mtime
- [ ] 路径标准化：`/` 与 `\`、相对路径、盘符均被正确处理
- [ ] 每个命令参数校验失败返回结构化错误；边界场景（不存在文件、空目录、长输出截断）行为正确
- [ ] 短名与别名（如 `list_directory`）调用一致
- [ ] 协议层 seam 测试覆盖全部命令的成功/失败/边界；破坏性操作结果可验证（文件系统状态断言）
