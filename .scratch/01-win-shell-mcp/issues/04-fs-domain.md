# 04-文件系统命令域

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 用户能通过 MCP 在真实文件系统中完成文件/目录操作：`ls`（列表）、`mkdir`（递归创建）、`rm`（递归删除）、`cp`、`mv`、`touch`、`stat`（元数据）、`find`（按文件名模式递归搜索）。全部路径参数自动标准化（分隔符/绝对相对/盘符），行为与 Unix 语义一致，遵循输出精简原则与信任模式。

**验收标准：**

- [ ] 每个命令在真实临时目录中可独立演示成功路径
- [ ] 每个命令参数校验失败返回结构化错误
- [ ] 边界场景（不存在文件、空目录、长输出截断）行为正确
- [ ] 路径标准化：`/` 与 `\`、相对路径、盘符均被正确处理
- [ ] 短名与别名（如 `list_directory`）调用一致
- [ ] 协议层 seam 测试覆盖全部命令的成功/失败/边界
