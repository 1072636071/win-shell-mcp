# 09-系统信息命令域

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 用户能查询系统信息：OS 信息（平台/版本/架构）、磁盘用量、内存总/可用、CPU 信息（核心数/型号/使用率，尽力而为）、主机名/当前目录/Node 版本、PATH 条目。纯 Node 实现（`os` 模块与磁盘查询），输出精简结构化 JSON。

**验收标准：**

- [ ] 系统信息返回 OS/arch/platform/hostname/cwd/node 版本（精简字段）
- [ ] 磁盘用量返回各盘/挂载点总容量与可用空间，Windows 与 unix 均正确
- [ ] 内存总/可用与 CPU 信息（核心数/型号/使用率，尽力而为，跨平台）
- [ ] PATH 条目列表化输出
- [ ] 输出遵循 token 最小化原则；跨平台分支均有测试
- [ ] 协议层 seam 测试覆盖各命令成功路径
