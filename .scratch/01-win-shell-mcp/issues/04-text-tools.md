# text 工具集

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** AI 可在单个文件内做行级匹配搜索（含大小写/上下文）、取头尾 N 行、统计行/词/字符、对比两个文件差异、按正则替换内容（可原地写回），全部返回极简结构化结果。

**验收标准：**

- [ ] grep 返回 `[{line, text}]` 且内容截断
- [ ] head/tail/wc/diff/replace 行为正确，含空文件与无匹配场景
- [ ] replace 支持返回结果与原地写回两种模式
- [ ] 各工具错误路径与边界有测试
