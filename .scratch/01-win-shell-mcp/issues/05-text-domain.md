# 05-文本处理命令域

**Status:** ready-for-agent

**Blocked by:** 02

**构建内容：** 用户能通过 MCP 读取与处理文本文件：`cat`（读文件，含编码自动转换）、`head` / `tail`（预览首/尾行）、`wc`（行/词/字节计数）、`grep`（正则搜索并返回命中位置与行内容）。遵循输出精简原则，长输出截断。

**验收标准：**

- [ ] 每个命令可独立演示成功路径
- [ ] GBK/CP936 编码文件读取后为正确 UTF-8 内容（不乱码）
- [ ] `head`/`tail` 支持指定行数；长输出按精简原则截断
- [ ] `grep` 支持正则、返回命中文件/行号/内容
- [ ] 参数校验失败与边界（文件不存在、空文件）返回结构化结果
- [ ] 协议层 seam 测试覆盖成功/失败/边界/编码
