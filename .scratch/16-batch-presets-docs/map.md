# 16-batch-presets-docs — map

> 工单拆解上下文指针与已做决策。对应 PRD：`.scratch/16-batch-presets-docs/PRD.md`（来源 PRD-07 优化点 P2-3）。

## 目标

在 `docs/batch-presets/` 下维护常见任务的 batch 编排模板：每个预设一个 markdown 文件（场景 + 可直接粘入 `batch_run` 入参 JSON + 断言与引用要点讲解 + 适用版本与维护状态行），外加一个索引页。纯文档、零代码，不违反 ADR-0015 对 recipe 执行器的否决。

## 关键决策

- **文档形态而非执行机制**：不做"按名字调用预设"，不做参数化模板引擎——预设是示例，不是模板语言（ADR-0015 否决边界）。
- **首批 4 个预设封顶**：读改写回、git 提交推送、批量文件采集、环境自检；低频场景不收，扩充需逐个论证频次。
- **语法基线**：断言操作符严格限 10 种枚举内（eq/neq/gt/gte/lt/lte/in/re/truthy/falsy）；引用仅 `{{stepId.output.path}}` 形式；步骤 `id` 显式命名；入参一律以 09 号工单落地后的默认极简输出形态为基准（不默认带 `verbose`）。
- **维护约定**：`batch_run` 语法或相关工具输出变更的工单须同批检查本目录是否过时；过时预设改状态标注而非悄悄留存。写进各预设维护状态行。
- **示例与实现一致性的验证**：文档本体不入测试（无文档渲染管线），用一次性实测替代——实测 2 个不涉外部状态的预设，静态核对 2 个涉外部状态的预设。

## 涉及文件

- 新增 `docs/batch-presets/index.md`：索引页（每预设一行：名称｜适用场景｜维护状态 + 链接）
- 新增 `docs/batch-presets/<preset-slug>.md` × 4：读改写回、git 提交推送、批量文件采集、环境自检
- 指针接入（非本工单落地）：10 号工单 `batch_run` description 末句指向本目录；13 号速查表 meta 节列一行。本工单提供被引用的落地物，接入由对应工单完成。

## 实施顺序

01（目录 + 索引 + 首批 4 个预设文档）→ 02（实测验收 2 个预设 + 静态核对 2 个预设）。01 阻塞 02。01 不阻塞于任何工单（语法基线依赖 09 号已落地形态，按基线撰写即可）；10/13 号指针接入依赖本工单的落地物。

## 超出范围

- 不做任何形式的预设执行机制（不接受"按名字调用预设"）——ADR-0015 否决边界
- 不做预设的参数化模板引擎（预设是示例，不是模板语言）
- 不收低频场景（首版 4 个封顶，扩充需逐个论证频次）
- 不做英文版
- 不改 `batch_run` 的 description（10 号工单负责）与速查表（13 号工单负责）本体，本工单只提供被引用落地物
