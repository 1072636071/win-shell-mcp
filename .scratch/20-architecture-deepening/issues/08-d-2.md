# D-2 — 兜底通道两兄弟 shell_exec 与 run_command 接口不对称

Status: ready-for-agent
强度：值得探索
域：process / shell_exec / run_command / pkg
工具：shell_exec, run_command
文件：src/tools/shell_exec.ts, src/tools/run_command.ts
来源：架构深化审查（jxx-improve-codebase-architecture，子 agent D）

## 问题

CONTEXT.md 把 shell_exec 与 run_command 合称「兜底通道」，二者应是同一抽象层的兄弟。但接口已不对称：(1) 超时参数命名不一致——shell_exec 用 timeout，run_command 用 timeoutMs；(2) encoding 类型不一致——shell_exec 是任意 string（运行期自动检测），run_command 是 enum ['utf8','gbk']；(3) run_command 无 verbose 参数，不返回 pid/duration，shell_exec 有；(4) run_command 有 maxOutputBytes（字节级截断预算），shell_exec 没有（用全局 getTruncateLimit 字符级截断）；(5) run_command 返回 signal 字段，shell_exec 不返回；(6) 截断语义不一致——run_command 是字节级尾截（保留预算内前缀），shell_exec 是字符级 truncate（追加 ...[truncated, N more chars] 标记）。不对称会让 AI 调用方在两个兜底通道间试错（该用 timeout 还是 timeoutMs？该传 encoding='gbk' 还是 encoding='gbk'？run_command 不返回 pid 怎么调试？），违反输出优先级链第 1 项「交互轮速最少」。

## 方案

统一兜底通道的公共参数与返回字段：① 超时参数统一为 timeoutMs（run_command 现名，shell_exec 改名，0.x 阶段允许破坏性改名，ADR-0007）；② encoding 统一为 string（运行期自动检测，shell_exec 现状，run_command 放宽 enum 限制）；③ run_command 增加 verbose 参数，返回 pid/duration（对齐 shell_exec）；④ 截断语义统一为字符级 truncate + truncated 标记（shell_exec 现状），run_command 的 maxOutputBytes 字节预算下沉到 run.ts RunOptions（与 D-1 一并改造）；⑤ signal 字段二选一——要么都返回要么都不返回（建议都不返回，signal 是底层细节，AI 决策不需要）。语义正当的不对称保留：shell_exec 有 shell 选项（auto/cmd）和 command 字符串，run_command 有 args 数组且无 shell 选项（本意不经 shell 解析）。

## 收益

① AI 调用方在两个兜底通道间零试错（参数命名、返回字段一致）；② 减少 ADR-0016 输出优先级链第 1 项的交互轮次损耗；③ 统一截断语义后，truncated 标记语义一致，AI 解读无歧义；④ 0.x 阶段统一，避免 1.0 后受 ADR-0007 兼容性红线约束无法修改。

## 前后

**之前（浅）：**
shell_exec:  { command, cwd, timeout, encoding: string, env, verbose, shell: auto|cmd, stdin }
  返回: { exitCode, stdout, stderr, truncated, [pid, duration] }
run_command: { command, args, cwd, env, timeoutMs, maxOutputBytes, encoding: 'utf8'|'gbk', stdin }
  返回: { stdout, stderr, exitCode, signal, truncated }

不对称：timeout vs timeoutMs、encoding string vs enum、verbose 有无、maxOutputBytes 有无、signal 有无、截断字符级 vs 字节级

**之后（深）：**
shell_exec:  { command, cwd, timeoutMs, encoding: string, env, verbose, shell: auto|cmd, stdin }
  返回: { exitCode, stdout, stderr, truncated, [pid, duration] }
run_command: { command, args, cwd, env, timeoutMs, encoding: string, stdin, verbose }
  返回: { exitCode, stdout, stderr, truncated, [pid, duration] }

统一：timeoutMs、encoding string、verbose、截断字符级 + truncated 标记、无 signal
保留正当不对称：shell_exec 有 shell 选项 + command 字符串；run_command 有 args 数组 + 无 shell（不经 shell 解析）
