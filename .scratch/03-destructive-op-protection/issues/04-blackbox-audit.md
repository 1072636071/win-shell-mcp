# 04 黑盒命令审计（shell_exec / run_command）

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 开启保护后，AI 通过 shell_exec / run_command 执行任意命令时，原始命令文本（含 shell 选项、stdin 输入）写入审计流，不备份、不拦截；未开启保护时不记录。

**验收标准：**

- [ ] 两个工具声明 protection 元数据（audit-only）
- [ ] 开启保护后执行命令，审计流新增一行含原始命令文本与结果
- [ ] 命令执行成功/失败均记录
- [ ] 未开启保护时不产生任何审计行，行为与现状一致
- [ ] 审计记录不含机密过滤逻辑（保持极简，与 ADR-0003 一致）
- [ ] 集成测试：开启/关闭两种状态下命令文本记录差异
