# 03 覆盖类破坏工具声明标注（6 个）

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** 开启保护后，fs_write 覆盖已有文件、fs_mv 覆盖已存在目标、fs_cp 复制覆盖 dest、text_replace 写回、archive_extract 解包落盘、net_download 落盘——六类覆盖场景先备份被覆盖目标再执行原操作；新建、追加、普通移动（无覆盖）、复制到不存在路径等非破坏场景不触发备份；命中低价值名单的目标直接覆盖不备份。

**验收标准：**

- [ ] 六个工具声明 protection 元数据（overwrite + 正确的目标路径参数），handler 零改动
- [ ] fs_write 覆盖已有文件时旧内容进回收站；新建与 append 不备份
- [ ] fs_mv 覆盖已存在 dest 时被覆盖目标进回收站；普通移动不备份
- [ ] fs_cp 复制到已存在 dest 时被覆盖目标进回收站；目标不存在不备份
- [ ] text_replace 写回时原文件进回收站
- [ ] archive_extract 解包覆盖已有文件时被覆盖目标进回收站
- [ ] net_download 落盘覆盖已有文件时被覆盖目标进回收站
- [ ] 六类覆盖场景命中低价值名单时直接覆盖不备份，审计行记录
- [ ] 每类覆盖场景的备份 + 审计集成测试（走工具分发全链路）
