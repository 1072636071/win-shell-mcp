# 02 回收站还原闭环（fs_trash_list + fs_restore）

**Status:** ready-for-agent

**Blocked by:** 01

**构建内容：** AI 可通过 fs_trash_list 查看回收站全部批次（操作 ID/原路径/时间/大小），通过 fs_restore 按操作 ID 把整批数据还原回原路径；原位置已有新文件时冲突报错而非覆盖；还原成功后该批次从回收站移除；还原动作本身在审计流中留痕。

**验收标准：**

- [ ] fs_trash_list 列出全部备份批次（操作 ID/原路径/时间/大小），空回收站返回空列表
- [ ] fs_restore 按操作 ID 读取 meta.json，将批次内容还原到原路径（目录递归还原）
- [ ] 原位置已有文件/目录时冲突报错（语义化、AI 可理解），不覆盖新数据
- [ ] 还原成功后批次目录移除；再次还原同一 ID 返回不存在错误
- [ ] 还原操作写入审计流（可追溯）
- [ ] 未知操作 ID 返回明确错误
- [ ] 单元测试：列批次、还原成功/冲突/移除、未知 ID、临时目录隔离
