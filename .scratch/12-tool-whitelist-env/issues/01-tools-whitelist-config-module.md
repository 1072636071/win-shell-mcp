# 工具白名单配置模块（公共 seam：env 解析纯函数）

**Status:** ready-for-agent

**Blocked by:** 无——可立即开始

**构建内容：** 新建本批优化唯一的新增代码 seam——一个纯函数配置模块，承担环境变量解析。初版接口为工具白名单解析：输入原始字符串或 `undefined`，输出"正名集合"或"未知条目"错误。模块内**不直接读 `process.env`**（读取留在唯一调用点），函数接受原始字符串入参，因此不启动进程即可单测。本模块是 11 号工单（`WIN_SHELL_LAZY`）与 15 号工单（`WIN_SHELL_TRUNCATE`）的公共地基：后续两个变量并入同一模块，其余代码只消费解析结果，env 读取不扩散成第二个事实源。

**验收标准：**

- [x] 新建配置模块（纯函数、无副作用、无全局态、不 import/read `process.env`），导出白名单解析函数；`WIN_SHELL_TOOLS` 变量名常量收敛于此模块
- [x] 解析输入：`undefined` 或空串 → 不过滤（返回空集合，调用方按"全量"处理）
- [x] 解析输入：逗号分隔正名 → 逐项 trim、忽略空段、重复项去重，输出去重后的正名集合
- [x] 解析输入：含未知条目（不在内置正名表内）→ 返回"未知条目"错误，错误携带全部非法条目的原文（而非仅第一个）
- [x] 未知条目判断基于内置工具**正名**集合；白名单语法中若出现别名（如 `ls`），因别名不在正名表内，同样归为未知条目（含该条原文）
- [x] 解析函数签名接受原始字符串或 `undefined` 入参（非 `process.env`），保证可注入测试
- [x] 解析逻辑用纯函数表驱动测试（`tests/contract` 先例）：正常名单 / 空串 / 纯空白 / 重复项 / 未知项 / 含别名的非法项 / `undefined`，覆盖 `errors.test.ts` 式逐条断言
- [x] 测试不启动进程、不读 `process.env`；覆盖率阈值保持成立
