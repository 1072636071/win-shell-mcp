# fail-fast 启动校验 + 文档（README 环境变量小节）

**Status:** ready-for-agent

**Blocked by:** 01, 02

**构建内容：** 部署者白名单拼错（写了不存在的工具名或别名）时，server 启动阶段即抛错退出、点名全部非法条目，让配置错误不静默生效（不做"忽略未知项"的宽容模式）。同时 README 新增"环境变量"小节，`WIN_SHELL_TOOLS` 作为本批优化首个变量写入，作为 11/15 号变量后续同节追加的共用槽位；13 号工单（AI 速查表）落地后同步一行。

**验收标准：**

- [ ] 白名单含未知工具名（含误写别名）时，启动阶段即抛错退出，错误信息列出**全部**非法条目原文（非仅第一个）
- [ ] 不做"忽略未知项"的宽容模式：**存在**未知项时启动失败并列出全部非法条目，而非丢弃未知项、以残缺白名单继续生效（fail-fast 语义固定，不静默降级为全量）
- [ ] 启动校验失败路径经配置模块纯函数的错误返回值等价覆盖（延续 01 号工单表驱动测试，不单测进程级退出码）
- [ ] README 新增"环境变量"小节，`WIN_SHELL_TOOLS` 条目说明语义（逗号分隔正名、空串/未设=全量、别名随正名、未知项启动失败），并注明是本批优化共用小节（11 号 `WIN_SHELL_LAZY`、15 号 `WIN_SHELL_TRUNCATE` 后续同节追加）
- [ ] 不承担 AI 速查表内容落地（13 号工单负责）；本工单仅在 13 落地后确认其中同步一行 `WIN_SHELL_TOOLS`
- [ ] CHANGELOG 增加本特性条目（或并入既有 Unreleased 段），说明默认行为不变、纯新增开关
