## 决策汇总

- **D1（2026-08-19）补充命令边界**：允许开辟新命令域，但每个新域必须单独论证（覆盖场景、不可替代性）并作为决策回写 CONTEXT.md；八域内的补全不受此闸门限制。
- **D2（2026-08-19）拓展判定标准**：以 AI Agent 日常高频场景为唯一判定标准。不为对齐 POSIX 而补参数；冷门场景保留 `shell_exec` 兜底通道。
- **D3（2026-08-19）决策粒度**：本 memorial 决策到「命令清单 + 优先级 + 一句话职责」；参数级设计（inputSchema、输出字段、错误码）在实施工单中细化。
- **D4（2026-08-19）ADR 编号**：保持既有重号现状，新 ADR 从 0006 起编；不改动既有文件、CONTEXT.md 引用不变。
- **D5（2026-08-19）兼容性红线**：分两阶段——发布前（当前 0.x）允许破坏性修改，应借机修正不合理设计；正式发布后只加不改（additive-only：仅新增可选参数与输出字段，默认行为与既有字段永不变）。
- **D6（2026-08-19）新域规模门槛**：不设最小规模；语义独立即可成域（即便只含 1-2 个命令）。每个新域仍须按 D1 逐域论证并回写 CONTEXT.md。
- **D7（2026-08-19）下载落盘形态**：独立新命令 `net_download`（net 域），返回 `{saved, bytes, path}`；`net_get` 保持「返回 body 文本」单一形态，不加 saveTo（吸收 E-02）。
- **D8（2026-08-19）命令批次决策清单**（agent 依用户授权裁定，判定依据 D1/D2/D5/D6）：

  **新命令（12 个，按优先级）**

  | # | 命令 | 域 | 优先级 | 一句话职责 |
  |---|------|----|--------|-----------|
  | 1 | `net_download` | net | P0 | 下载 URL 内容落盘，返回 saved/bytes/path（D7） |
  | 2 | `archive_create` | **archive（新域）** | P0 | 打包目录/文件为 tar/zip |
  | 3 | `archive_extract` | **archive（新域）** | P0 | 解包 tar/zip 到目标目录 |
  | 4 | `git_checkout` | git | P1 | 切换/创建分支、还原工作区文件 |
  | 5 | `git_push` | git | P1 | 推送提交到远端 |
  | 6 | `git_pull` | git | P1 | 拉取远端并合并 |
  | 7 | `git_clone` | git | P1 | 克隆仓库到本地 |
  | 8 | `git_stash` | git | P1 | 暂存/恢复工作区改动 |
  | 9 | `hash_file` | **hash（新域）** | P1 | 计算文件 sha256/md5，校验下载完整性 |
  | 10 | `fs_du` | fs | P1 | 递归累计目录大小，定位占空间目录（吸收 E-27，归 fs 而非 system_disk 扩展：操作对象是目录树而非文件系统） |
  | 11 | `net_listen` | net | P1 | 列出本机监听端口及占用进程 |
  | 12 | `json_get` | **json（新域）** | P1 | 按路径取 JSON 文件/字符串中的值（jq-lite） |

  **新域论证（按 D1）**：archive——归档格式跨 tar/zip，是「打包/解包」独立场景，非纯文件读写，fs 域无法承接；hash——基于 node:crypto 的摘要计算，语义独立于文本处理与文件读写；json——结构化数据路径取值，与 text 域的「按行处理」范式不同。三者均语义独立，按 D6 可成域。

  **现有命令拓展（13 项，全 P1）**

  | # | 项 | 拓展内容 |
  |---|----|---------|
  | 1 | E-01 | net_get/net_post 加 `headers` 自定义请求头 |
  | 2 | E-04 | git_diff 加 `against` 目标 ref |
  | 3 | E-07 | search_content 支持正则（与 text_grep 对齐） |
  | 4 | E-10 | process_list verbose 加 cmdline；filter 改大小写不敏感 |
  | 5 | E-11 | process_kill 加 `tree` 进程树终止 |
  | 6 | E-12 | shell_exec 加 `shell` 选项（cmd/powershell/auto） |
  | 7 | E-13 | shell_exec/run_command 加 `stdin` |
  | 8 | E-15 | fs_list 加排序/类型与 glob 过滤；verbose 补 mtime |
  | 9 | E-16 | fs_write 加自动建父目录（默认行为留实施工单定） |
  | 10 | E-17 | fs_mv 加 `overwrite`；dest 为目录时移入该目录 |
  | 11 | E-21 | **正确性修复**：text_replace 写回沿用源编码（不再静默改写 GBK 为 UTF-8） |
  | 12 | E-22 | **正确性修复**：text_diff 引入真行级 diff 算法（LCS/Myers），替换朴素逐行对比 |
  | 13 | E-25 | system_info 加当前时间（ISO 8601）（吸收 M6，选扩展不新命令：system_info 是天然归属） |

  **P2 提拔（2 项）**：E-19 统一 fs_read 与 cat 的区间语义（借 D5 发布前窗口消除 AI 选错工具的重叠歧义）；E-31 env_get 全量返回加 filter 与截断（对齐极简输出原则）。

  **不做（其余 P2，共 23 项）**：M9 符号链接、M10 watch、M11 base64、M12 剪贴板、M13 CSV、M14 open，及 E-03/E-05/E-06/E-08/E-09/E-14/E-18/E-20/E-23/E-24/E-26/E-28/E-29/E-30/E-32/E-33——按 D2 均属低频/锦上添花，保留 `shell_exec` 兜底，待真实使用信号再议。
