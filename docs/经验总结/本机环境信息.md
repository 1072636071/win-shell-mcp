## 已知环境限制（重要）

- **junction（目录联接）穿越被系统安全策略禁用**（2026-08-30 诊断）：本机任何 junction 访问均报 `untrusted mount point`（独立测试 C→C、C→D junction 均失败，属系统性问题，非特定目录）。影响：
  - pnpm `link:` 依赖不可用，`dsh plugin add link:<path>` 会失败（报 `UNKNOWN: unknown error, open ...package.json`）
  - dsh profile 的 `.dsh-module-fallback` 链接结构不可穿越，`node_modules` 内 junction 型包不可读
  - 本机安装 dsh 插件需改用 `file:` 拷贝方式（`pnpm add file:<path>`），或改到 junction 正常的桌面终端执行
- **dsh CLI 未全局安装**：`npm ls -g` 无 `@deepseek-ai/dsh`；deepseek-harness 源码 CLI（`apps/cli/lib/bin.js`）因 workspace 依赖链接不完整亦不可直接运行。
