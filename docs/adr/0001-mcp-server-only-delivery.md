# ADR-0001: 交付形态仅 MCP Server

- 状态：已接受
- 日期：2026-08-18

## 背景

win-shell-mcp 定位为可发布开源产品（npm 包 + MCP Server）。交付形态存在两条路线：① MCP Server + 薄 CLI（命令实现拆为独立库，两者复用）；② 仅 MCP Server。

## 决策

**仅交付 MCP Server**，单一入口，命令以 MCP tool 暴露。不拆分独立核心库、不提供 CLI 层。测试通过 MCP SDK 直接调用工具实现（或测试专用入口）进行。

## 后果

**正面**
- 维护面最小；无冗余 CLI 语法需设计。
- 包体积小、心智负担低。
- 与"AI 调用工具"的产品定位一致。

**负面 / 代价**
- 手动调试需启动 MCP server 或编写 SDK 测试客户端。
- 无脚本化 CLI 通道（CI 中验证行为依赖测试而非命令行）。

## 备选方案（被否决）

- **MCP + 薄 CLI**：命令实现复用成本低，但增加 CLI 语法设计、文档、发布面；当前阶段收益不明确。
- **CLI 优先，MCP 后续**：与"AI 调用工具"的核心定位不符，且需二次重构暴露为 tool。
